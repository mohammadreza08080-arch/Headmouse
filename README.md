## ✨ Features
- 🖱️ Move the cursor with your head
- 😉 Left wink = left click, right wink = right click
- 📷 Choose between multiple cameras
- 🎨 Clean, modern UI
- 🪟🐧 Works on Windows and Linux

## 📥 Download

| Platform | File | Notes |
|----------|------|-------|
| Windows 10/11 | [HeadMouse-Windows.zip](https://github.com/USERNAME/headmouse/releases/latest) | Extract and run `HeadMouse.exe` |
| Debian / Ubuntu / Kali | [headmouse_amd64.deb](https://github.com/USERNAME/headmouse/releases/latest) | `sudo apt install ./headmouse_*.deb` |

## 🚀 Usage
1. Launch HeadMouse and pick your camera
2. Sit facing the camera in good lighting
3. Move your head to move the cursor, wink to click

## ⚠️ Notes
- Linux: an X11 session is required (Wayland is not supported yet)
- Windows may show a SmartScreen warning because the app is unsigned

## 🛠️ Run from source
```bash
git clone https://github.com/USERNAME/headmouse
cd headmouse
pip install -r requirements.txt
python -m headmouse.main
```
